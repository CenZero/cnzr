# Security Policy for CNZR Framework

Below are the versions of the CNZR framework that are currently being supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| 0.x.x   | :x:                |

*(Note: Sesuaikan nomor versi di atas dengan status rilis repository CNZR kamu saat ini).*

## Reporting a Vulnerability

We take the security of the CNZR framework seriously. If you discover a security vulnerability, please do not disclose it publicly via GitHub Issues or discussions. 

Instead, please report it to us privately by sending an email to **[masukkan email kamu, misal: security@cenzero.biz.id]** or via GitHub Private Vulnerability Reporting (if enabled).

**What to expect:**
* **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **[misal: 48 hours]**.
* **Updates:** You can expect regular updates regarding our investigation and the progress of the fix.
* **Action:** If the vulnerability is accepted, we will develop a patch, backport it to supported versions, and credit you for the discovery when we publish the security advisory.

Thank you for helping keep the CNZR framework secure and safe for everyone!
